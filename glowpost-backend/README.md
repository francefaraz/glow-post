# GlowPost Backend (Node.js + Supabase)

This is the complete backend for GlowPost.

## Quick start

1. Copy `.env.example` to `.env` and fill values.
2. Run `npm install`
3. Run `npm run dev` or `node server.js`
4. Import `supabase.sql` into your Supabase SQL editor to create tables.

API endpoints available under `/api/*`. See code in `/routes`.
